# Test kullanıcısı davet mesajları

## 1. İlk mesaj (katılmak ister misin?)

**Türkçe**
```
Merhaba! Japonca öğrenmek için bir uygulama yaptım: Pio Pio Nihongo 🐣 (kanji, kelime, gramer, günlük konuşmalar). Google Play'e çıkabilmesi için 14 gün boyunca test eden 12 kişiye ihtiyacım var. Android telefonun ve Gmail'in yeterli, ücretsiz. Yardım eder misin? Katılırsan sana linki göndereyim 🙏
```

**English**
```
Hi! I made an app for learning Japanese: Pio Pio Nihongo 🐣 (kanji, words, grammar, everyday conversations). To publish it on Google Play I need 12 people to test it for 14 days. You just need an Android phone and a Gmail account, and it's free. Would you help? If yes, I'll send you the link 🙏
```

## 2. Link mesajı (kapalı test onaylandıktan sonra)

**Türkçe**
```
Teşekkürler! 🐣
1) Önce şu gruba katıl: GRUP_LINKI
2) Sonra bu linkten "Test kullanıcısı ol"a bas: TEST_LINKI
3) Aynı sayfadaki "Google Play'den indir" ile uygulamayı kur.
Önemli: 14 gün boyunca testten çıkma ve uygulamayı silme. Arada bir açıp kullanman yeterli. Bir hata görürsen uygulamada Ayarlar → Hata bildir ile yazabilirsin.
```

**English**
```
Thank you! 🐣
1) First join this group: GROUP_LINK
2) Then open this link and tap "Become a tester": TEST_LINK
3) Install the app with "Download it on Google Play" on the same page.
Important: please stay in the test and keep the app installed for 14 days. Opening it now and then is enough. If you see a problem, use Settings → Report a mistake in the app.
```

`GRUP_LINKI`: Google Grubunun adresi (ör. https://groups.google.com/g/piopio-test)
`TEST_LINKI`: Play Console → Closed testing → Testers → "Join on the web" linki
